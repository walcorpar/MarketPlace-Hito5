## 🛠️ Tecnologías Utilizadas

- **Frontend:** React 18, Vite, React Router DOM, Context API, Axios, CSS Modules.
- **Backend:** Node.js, Express, PostgreSQL (`pg` pool con SSL), JSON Web Token (`jsonwebtoken`), Bcryptjs, CORS.
- **Infraestructura:** Render (Web Service, Static Site y Managed PostgreSQL).
